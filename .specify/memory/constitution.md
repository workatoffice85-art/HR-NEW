# دستور نظام الحضور والانصراف الذكي (HR Attendance System Constitution)

## المبادئ الأساسية (Core Principles)

### الأول: الخصوصية الفائقة وأمان البيانات البيومترية (I. Absolute Privacy & Biometric Security)
تعتبر البيانات البيومترية (بصمات الوجه والإصبع) بيانات حساسة للغاية ومحمية بالكامل. يجب معالجتها محلياً وتشفيرها بشكل آمن باستخدام خوارزميات التشفير المتقدمة (HMAC SHA-256) قبل الحفظ في قاعدة البيانات. يمنع منعاً باتاً نقل الصور أو البصمات الخام عبر الشبكة.

### الثاني: دعم كامل للغة العربية والتصميم المتجاوب (II. RTL & Responsive Visual Excellence)
يجب أن يدعم الموقع واجهة مستخدم عربية احترافية بالكامل متوافقة مع اتجاه RTL (Right-to-Left)، مع الحفاظ على تجربة مستخدم premium وجماليات راقية (خط Tajawal، تأثيرات Glassmorphism، وتدرجات لونية متناسقة) تتكيف بسلاسة مع جميع مقاسات الشاشات والهواتف الذكية.

### الثالث: موثوقية الموقع الجغرافي والتحقق المحكم (III. Reliable Geofence & Verification)
يجب التحقق بدقة من النطاق الجغرافي (Geofencing) المعتمد لكل موقع حضور، والتأكد من منع التلاعب بالإحداثيات الجغرافية (Mock Location Prevention) لضمان نزاهة وموثوقية عمليات الحضور والانصراف.

### الرابع: كفاءة الأداء والتخزين الذكي (IV. High Performance & Smart Caching)
للحفاظ على البقاء في الفئة المجانية لـ Supabase (أقل من 500 ميجابايت)، يجب تفعيل آلية التخزين المؤقت الذكي (Stale-While-Revalidate) للبيانات المتكررة، وتشغيل الأرشفة الدورية التلقائية للبيانات القديمة بشكل دوري.

### الخامس: المنهجية القائمة على المواصفات (V. Spec-Driven Development - SDD)
يتم تنفيذ وتعديل ومراجعة أي كود أو واجهة في النظام بناءً على دورة SDD صارمة: المواصفات (Spec) -> خطة التنفيذ التقنية (Technical Plan) -> المهام الإجرائية (Tasks) -> التحقق والاختبار (Verification).

## معايير التطوير والقيود (Development Standards)
- **لغات التطوير**: HTML5, Vanilla CSS3, Modern JavaScript (ES Modules), Supabase JS Client, Express.js.
- **التوافق الجغرافي**: استخدام Geolocation Web API وتحديث النطاقات الجغرافية مع تطبيق الجوال بشكل آمن.
- **أمن الواجهة**: تعقيم جميع مدخلات المستخدمين لمنع ثغرات XSS، وتطبيق حماية CSRF، واستخدام التحقق المشفر بالرموز (HMAC Secure Tokens) للإجراءات الحساسة المرسلة عبر البريد الإلكتروني.

## الحوكمة وإجراءات التعديل (Governance)
